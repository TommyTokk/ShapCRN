# Example models

This directory is intentionally excluded from ShapCRN source and wheel
distributions. Files whose names begin with `BIOMD` were obtained from or
derived from the corresponding BioModels accession. Their original records
and redistribution terms should be consulted before copying or republishing
them.

`KnockinModelV2.xml`, `diff_model.xml`, and generated `_ko_`/`_ki_` variants
are development fixtures. Their provenance and redistribution status must be
documented before they can be included in a published package.

The MIT license for ShapCRN's source code does not replace any license or terms
that apply to third-party biological models.
